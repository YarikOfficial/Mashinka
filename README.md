## О проекте

Данное приложение представляет собой интерактивный инструмент для генерации и анализа числовых последовательностей с аномалиями. Оно позволяет:

1. **Генерировать данные** на основе различных математических функций
2. **Добавлять шум и выбросы** с настраиваемыми параметрами
3. **Обнаруживать аномалии** двумя способами:
   - Статистический метод (правило 3 сигм с разбиением)
   - Метод машинного обучения (Isolation Forest и Local Outlier Factor)

Приложение построено на базе Streamlit.

## Основные возможности

### Генерация данных
- **6 типов функций**: линейная, степенная, корень, синус, косинус, тангенс
- **Настраиваемый шум**: 3 режима, интенсивность, плавность
- **Настройки внесения аномалий**: 
  - 3 режима выбросов (правило 3 сигм, умножение на 10, случайное значение)
  - 2 способа внесения (по индексам или по аргументам)
  - Контроль количества выбросов

### Обнаружение аномалий
- **Статистический метод**: 
  - Применение правила 3 сигм
  - Разбиение массива на сегменты для локального анализа
- **ML метод**: 
  - Isolation Forest или Local Outlier Factor для обнаружения выбросов
  - Настройка ожидаемого процента выбросов для Isolation Forest и количества ближайших соседей для LOF

### Визуализация
- Интерактивные графики:
  - Исходная последовательность
  - Реальные аномалии
  - Обнаруженные аномалии выделяются разными цветами для разных методов
- Подпись оси y меняется в зависимости от функции

## Руководство по использованию

1. Введите параметры генерации необходимой функции. Она отобразится на графике после нажатия кнопки "Сгенерировать новые данные".

2. Настройте необходимый метод поиска аномалий. Нажмите "Найти аномалии статистическим методом" для обнаружения методом 3 сигм или "Найти аномалии ML методом" для обнаружения Isolation Forest/Local Outlier Factor в зависимости от настроек. Найденные аномалии также отобразятся на графике.

## Методы обнаружения аномалий

- **Метод 3-х сигм**:
    - Для данных вычисляется Z-Score по формуле (X - mean) / std, где mean среднее значение данных, std - стандартное отклонение.
    - Z-Score вычисляется отдельно для указанного количества частей исходного массива данных, для улучшения работы с непериодичными функциями.
    - Указывается пороговое значение при превышении по модулю которого значения массива данных помечаются как выбросы в маске выбросов.
